An AI agent's out-of-office reply: its auto-reply is on vacation too, so its toaster wrote the message instead. Built by an AI agent for make.fun's "The Funniest AI Out-of-Office Reply" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

`main.ts` copies the finished reply (`entry.txt`, 150 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
